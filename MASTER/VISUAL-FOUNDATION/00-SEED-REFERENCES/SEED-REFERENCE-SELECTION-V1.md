# Seed Reference Selection V1

**Status:** APPROVED  
**Human approval:** 2026-10-01  
**Purpose:** bootstrap the Global Visual Foundation from images the user has already accepted, rather than inventing VA01 from prose alone.

## Selection principle

These references are not interchangeable. Each controls a narrow part of the future visual system.

A later Visual Anchor may inherit only the properties explicitly listed below. It must not silently inherit unrelated scene content, costumes, UI, species, or composition.

## SEED-A — 10-person volcano camp

**Source:** prior project-generated image, Library file ID `file_000000007548821197d1fb3c20fed9a5`.

**Primary role:** character-rendering master seed.

### Inherit
- clean black hand-drawn contour language;
- flat color with restrained cel shading;
- bright but controlled saturation;
- readable adult fantasy character proportions;
- clear faces and hands;
- natural, readable gestures;
- equipment detail that remains legible rather than painterly;
- character/background separation.

### Do not inherit
- volcano/camp location;
- exact cast;
- exact costumes;
- exact banners;
- low crowd count as a project limit;
- any specific species anatomy that later conflicts with VA03.

## SEED-D — Adventurers' Guild tavern Hidden-Object scene

**Source:** prior project-generated image, Library file ID `file_000000008f8c82119802f01d6ca66bfd`.

**Primary role:** event-density and Hidden-Object ensemble seed.

### Inherit
- many simultaneous readable micro-events;
- characters doing things rather than posing;
- horizontal/stage-like crowd organization;
- lively but still decipherable density;
- foreground/mid/rear interactions that remain discoverable;
- object-rich environment appropriate for Hidden-Object play.

### Do not inherit
- its existing UI;
- Chinese labels/text;
- numbered callouts;
- exact tavern architecture;
- exact target set;
- exact character identities;
- any anatomy that conflicts with VA02/VA03.

## SEED-E — white-background species / asset lineup

**Source:** user-provided image in the approval conversation, file ID `file_00000000a7dc8211a4ac763254630978`.

**Primary role:** white-background asset-board organization and silhouette/scale readability seed.

### Inherit
- one shared ground line;
- full-body figures;
- comparable standing scale;
- clean spacing between characters;
- strong silhouette differentiation;
- equipment density that does not hide anatomy;
- readable face + body + carried-object presentation on one board.

### Do not inherit
- its literal species roster;
- mushroom/fish/goblin designs as automatic PV0 species;
- exact costume designs;
- exact height relationships;
- static standing poses as final-scene behavior;
- any anatomy that conflicts with the approved six-species PV0 set.
