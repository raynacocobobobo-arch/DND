# Global Visual Foundation V1

## Mission

Keep all 15 complete Hidden-Object levels visually recognizable as one art system and one product across long production gaps and different conversations.

## Two-part canon

1. Rule Bible: textual constraints, workflow, evidence, Gate logic and versioning.
2. Visual Bible: locked reference images, deterministic UI assets and the manifest that defines what each visual controls.

## Project-level milestones

- **PV0 — Global Visual Prelock:** required before formal Gate 3 asset production.
- **PV1 — Gold Master Lock:** created only after S02 Candlekeep passes Gate 7.

PV0 does not approve any level Gate. PV1 does not replace specialized anchors.

## Anchor classes

- VA01 Style Calibration
- VA02 Human / Face / Hand
- VA03 Species Master
- VA04 Class & Social Role Action
- VA05 Expression & Interaction
- VA06 Crowd Composition
- VA07 Material / Prop Rendering
- VA08 Anti-Drift
- Deterministic UI component and mockup anchors
- Gold Master Scene / Level anchors after PV1

## Inheritance rule

Every anchor must declare what it controls and what must not be inherited from it. Scene-specific boards may not override global anchors outside their declared scope.

## Priority

1. Specialized locked anchor for the feature it controls.
2. Gold Master for integrated behavior after PV1.
3. Style Calibration for general rendering.
4. Approved scene-specific board for local content.
5. Prompt text.

## Versioning

- V1: first locked usable foundation.
- V1.1: compatible/additive extension.
- V2: structural visual revision.

Never overwrite a LOCKED anchor in place while retaining the same version.
