# Hidden-Object UI Spec V1

**Status:** REVIEW  
**Source of truth:** `UI-TOKENS-V1.json` + `UI-COMPONENTS-V1.svg`

## Purpose

All 15 levels use one deterministic interface system. Scene art is approved without UI through Gate 5; UI is composited afterward from the same locked components.

The UI may change content, but not visual grammar, geometry, spacing, state language, or component construction inside one UI version.

## Non-negotiable rule

> **Do not ask an image-generation model to redraw the interface.**

Image generation produces scene art and visual-anchor imagery. UI is assembled from vector/tokens after the scene exists.

## Reference canvas

- Final reference canvas: **3840 × 2160**
- Aspect ratio: **16:9**
- Values in `UI-TOKENS-V1.json` are the canonical geometry/tokens.
- The component PNG is a review preview, not the source of geometry.

## Components

Required reusable components:
- `level-title`
- `clue-panel`
- `target-bar`
- `target-slot`
- `state-selected`
- `state-found`

They are defined in `UI-COMPONENTS-V1.svg`.

## Layout

### Target bar
- Bottom overlay.
- Up to six target slots are visible at once in V1.
- More targets use pagination/scroll behavior in implementation; they do not change slot geometry.
- Target content may vary by level.
- Bar geometry and slot spacing may not vary by level.

### Level title
- Compact top-corner card.
- Content changes by level.
- Geometry and hierarchy remain fixed.

### Clue panel
- Temporary/contextual top panel.
- Text changes by target/level.
- It must not become a permanent large overlay that competes with the scene.

## States

### Default
Neutral border / normal opacity.

### Selected
Uses the selected-state ring only. Do not redesign the slot.

### Found
Uses the found-state ring + completion mark and reduced emphasis.

Additional per-level states require a UI version change or an explicit compatible minor extension.

## Palette principle

The UI uses a subdued dark-panel + warm-metal-border + parchment-content family so it reads as part of the fantasy product without competing with scene color.

The palette is a product layer, not a location palette. Icewind Dale, Avernus, Candlekeep, and Rock of Bral do **not** get different UI themes.

## Typography

Typography hierarchy is defined in tokens. The current component board uses a preview font only.

Before PV0 can be LOCKED:
- production fonts must be finalized/bundled or otherwise made reproducible;
- changing the production font after lock requires a compatible UI revision.

## Safe-area rule

Blocking and final composition must preserve the UI safe area, but UI is not baked into Gate 5 scene art.

The same scene file must exist without UI.

## Target thumbnail rule

Target thumbnails:
- derive from approved target assets/crops;
- use the same slot inset;
- may not receive a different illustration style;
- may not contain extra decorative backgrounds that reduce object recognition.

## Deterministic regeneration

The canonical source is tokens + SVG.

A PNG preview may differ at the byte level across SVG renderers or font stacks. Therefore V1 determinism is established by:
1. exact JSON token equality;
2. exact SVG source hash/version;
3. stable component IDs and geometry;
4. later PV0 review of the rendered result.

## Full Mockup

`UI-FULL-MOCKUP-V1.png` is intentionally deferred until Task 8, when it is composited on the calibration scene.

It must not be generated by an image model and is not a Gold Master.
