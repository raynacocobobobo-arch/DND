# VA06 — Crowd Composition Spec V1

**Status:** DRAFT SPEC  
**Positive seed:** SEED-D for event density; SEED-A for figure readability.  
**Excluded:** B and C must not be used.

## Controls
VA06 locks the project’s crowd and spatial grammar:
- stage-like horizontal organization;
- weak/compressed perspective;
- readable rear figures;
- 8–12 event islands;
- foreground/mid/rear scale compression;
- background subordinate to people.

## Scale bands
- foreground: 105–110%;
- core midground: 100%;
- rear/high platform: 85–90%.

These are screen-treatment bands, not species anatomy.

## Required board panels
1. **GOOD: event-island map** — 8–12 colorless/diagrammatic clusters across a wide canvas.
2. **GOOD: rendered crowd crop** — at least 20–30 figures demonstrating compressed depth.
3. **GOOD: scale-band comparison** — same-size reference figures at 105/100/85–90 treatment.
4. **BAD: deep perspective** — rear figures collapse into dots.
5. **BAD: giant foreground** — foreground portrait blocks scene.
6. **BAD: uniform scatter** — many people with no events.
7. **BAD: one giant cluster** — crowd unreadable despite correct count.

Bad examples are diagnostic miniatures, not positive anchors.

## Event-island grammar
Typical finished scene:
- 3–4 A-level islands;
- 4–5 B-level islands;
- 2–4 C-level islands;
- usually 3–7 figures per island.

Each island should carry:
- primary action;
- secondary reaction;
- eye-line relationship;
- readable prop;
- micro-conflict, cooperation or consequence.

## Core statement
**A character comic that contains a setting, not a big setting containing many characters.**

## Pass criteria
- viewer reads people/events before architecture;
- rear figures remain identifiable as people with actions;
- no event island swallows half the cast;
- natural negative space prevents visual soup.

## Reject conditions
- cinematic one-point depth dominating the composition;
- tiny rear crowds;
- giant cropped foreground heads;
- background-detail competition;
- “60 isolated poses.”
