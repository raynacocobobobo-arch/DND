# Global Visual Foundation

Purpose: lock the visual DNA shared by all 15 D&D 5E Hidden-Object levels.

- PV0 = pre-production visual lock required before formal Gate 3 asset production.
- PV1 = Gold Master lock created only after S02 Candlekeep passes Gate 7.
- G0–G7 remain the per-level production gates.
- Canonical anchors are specification assets, not casual mood-board references.
- Only anchors with status `LOCKED` are canonical production references.
- UI is deterministic and component-based; Gate 5 scene art contains no UI.
- Every locked anchor is identified by version, scope, priority and SHA-256.

Authority order for conflicting references is defined in `GLOBAL-VISUAL-FOUNDATION-V1.md` and the manifest.
