# 15-Level Visual Inventory V1

## Purpose

This is **not a population lock**. It is a project-wide visual-capability inventory derived from the locked 15-level list and the current master research.

It identifies what the Global Visual Foundation must be able to render consistently before later levels reach Gate 3. It **does not approve Gate 2** for any scene and does not convert likely/possible species into official population statistics.

Evidence rule: location-specific unusual species/creatures remain tied to the scene research. Common SRD humanoids listed as likely recurring are a visual-system coverage need, not a claim that every listed species must appear in that scene.

## Cross-level capability findings

### High-frequency humanoid baseline candidates
The current 15-level corpus makes the following worth considering for PV0 coverage because they either appear in the Candlekeep proposal or recur naturally across multiple urban/expedition contexts:
- Human
- Elf
- Dwarf
- Halfling
- Gnome
- Tiefling

This list is still subordinate to the explicit Candlekeep Gate 2 decision. It is a visual-foundation planning result, not an official setting statistic.

### Strong extension candidates after PV0
These should not be forced into the first core board unless the pilot or inventory proves immediate need:
- Tabaxi
- Lizardfolk
- Duergar
- Derro
- Storm Giant
- Fairy
- Harengon
- Spelljammer-specific species set
- fiend families

Creature/scale systems such as dinosaurs, giant snails, dragons, infernal war machines and spelljammer craft are production extensions, not automatically humanoid Species-board entries.

## UI finding

No locked scene currently justifies a separate UI design. Different environments require contrast/safe-area testing, not different component geometry. The project should maintain one deterministic UI version unless a real implementation constraint proves otherwise.
