# VA04 — Class & Social Role Action Spec V1

**Status:** DRAFT SPEC  
**Style inheritance:** VA01/VA02/VA03 once locked.

## Controls
VA04 locks how role is communicated through:
- equipment;
- body use;
- task;
- stance;
- purposeful magic.

It does not define one fixed uniform per class and does not create a reusable actor library.

## Core role families
The board must cover enough examples to define the system:

### Adventuring / class families
- martial front-line;
- agile/stealth;
- arcane study/casting;
- divine/support;
- nature/ranged;
- social/performance.

Examples may map to Fighter, Rogue, Wizard, Cleric, Paladin, Ranger, Bard, Druid, Warlock, Sorcerer, Monk and Barbarian, but no class is reduced to one costume.

### Common social / institutional roles
- guard;
- scribe/scholar;
- priest/officiant;
- scout;
- worker/craftsperson;
- courier/porter;
- merchant;
- noble/administrator.

## Required board panels
At least 12 role cells. Every cell must show:
- readable full or 3/4 body;
- one task;
- one characteristic tool/equipment set;
- action line;
- short role label.

At least four cells must involve another person or object rather than isolated posing.

## Purposeful magic rule
If magic is shown, it performs a job:
- Mage Hand moves/retrieves;
- Mending repairs;
- Detect Magic investigates;
- healing/support assists;
- illusion communicates/distracts.

No idle glowing-orb pose.

## Pass criteria
A viewer should infer role from action + equipment before reading the label.

## Reject conditions
- every Wizard in robe + pointy hat;
- every Rogue in black hood;
- every Cleric in identical white/gold;
- magic as decorative glow;
- neutral museum poses;
- role silhouette overriding species anatomy.
