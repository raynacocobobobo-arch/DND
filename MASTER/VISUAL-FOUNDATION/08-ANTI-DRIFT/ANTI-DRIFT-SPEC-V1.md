# VA08 — Anti-Drift Spec V1

**Status:** DRAFT SPEC

## Purpose
VA08 is a canonical rejection board. It tells future generators and reviewers what counts as visual drift.

It does not borrow rejected project images B/C as reference material. Its bad examples are purpose-built diagnostics.

## Required failure examples
Each example must be visibly labeled with one failure category:

1. photorealism;
2. painterly concept-art rendering;
3. 3D-render / game-cinematic look;
4. anime/manga face system;
5. chibi proportions;
6. deep perspective with microscopic rear crowd;
7. giant foreground character blocking the ensemble;
8. background more detailed than characters;
9. random decorative glow-orb magic;
10. species anatomy drift;
11. repeated neutral/clone faces;
12. UI visually redrawn in a different style.

## Required comparison format
Where possible, show paired mini-panels:
- ACCEPTABLE principle;
- REJECTED drift;
- short failure label.

The positive side should reference locked VA01–VA07 principles rather than inventing a second positive style.

## Pass criteria
A reviewer should be able to point to a bad output and classify the failure using VA08 vocabulary.

## Reject conditions for VA08 itself
- unlabeled “bad art” collage;
- use of user-rejected B/C as implicit positive or negative canon;
- humorous distortions so extreme they fail to diagnose realistic production drift;
- contradictions with VA01–VA07.
