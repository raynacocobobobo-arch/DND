# VA03-TIEFLING — Tiefling Species Variation Spec V1

**Status:** DRAFT SPEC  
**Parent style:** VA01  
**Humanoid grammar:** VA02

## Controls
Locks Tiefling adult anatomy and project-default visual sample range.

## Required board
Six adult Tieflings on one ground line, including height/body/age/sex-presentation variation. Use red-family skin as the primary project sample palette, with visibly different red values rather than six identical reds.

## Invariants
- approximately Human-scale adult body;
- horns integrated into skull/silhouette;
- functional tail;
- adult humanoid hands/feet;
- no default wings.

## Variables
Height within Human-like range, body type, age, face family, hair, horn shape, horn orientation, tail thickness/curve, red-family skin value.

## Do not inherit
Exact horn shape, exact red value, clothing, class, “demonic” personality.

## Forbidden misreads
No horns, no tail, automatic wings, all Tieflings same face/horns, purple/gray treated as this project's default sample, one figure just a scaled copy of another.

## Project color note
The PV0 board's primary default skin samples are red-family (e.g. crimson, brick, warm red, dark muted red). This is a project visual-default rule, not a claim that all D&D Tieflings universally have red skin.
