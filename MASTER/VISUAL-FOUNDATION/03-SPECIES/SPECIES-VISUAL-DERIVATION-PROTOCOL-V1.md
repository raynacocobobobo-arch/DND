# Species Visual Derivation Protocol V1

**Status:** ACTIVE GLOBAL RULE  
**Applies to:** VA03-HUMAN / ELF / DWARF / HALFLING / GNOME / TIEFLING and all later species extensions.

## Purpose

Prevent species design from being invented from prompt language or derived from another species' body.

Every species must be built in the same evidence order:

> **Official 5E/SRD facts → approved VA01 species exemplar → Species Anatomy Core → controlled variation/chassis spec → approved board/rendering grammar → one-sample preflight → full board**

A later step may not override an earlier authority in the domain it controls.

## Step 1 — Official 5E / SRD facts first

Before writing or generating a species board, read the current project-approved official rules source.

Record only visually relevant facts:
- official size/height information;
- clearly described body/silhouette traits;
- mandatory anatomy;
- lineage/subspecies structure when relevant;
- age/longevity only when it affects the diagnostic board;
- explicit prohibitions implied by official identity.

Do not infer visual anatomy from class stereotypes, occupations or common fan art.

If the repository Master Research already contains the official evidence, verify it against the official source rather than relying on memory.

## Step 2 — VA01 species exemplar second

VA01 is the approved project translation of the D&D source material into this project's art family.

For every PV0 species, inspect the matching figure in:
`VA01 Style Calibration Board V3 → CORE SPECIES LINEUP`.

Use that figure to derive:
- project silhouette;
- project body/head proportion;
- limb-mass treatment;
- head/face relationship;
- how the official species description is stylized in the approved art language.

Do not inherit sample-specific accidents such as:
- exact beard;
- exact hairstyle;
- exact clothing;
- exact equipment;
- exact expression.

VA01 controls the **project visual translation** of official species facts.

## Step 3 — Build a Species Anatomy Core

Before chassis or character variation, write a short Anatomy Core containing:
- relative height;
- project head/body relation;
- torso/ribcage structure;
- limb length/mass;
- hand/foot mass;
- center of gravity;
- signature anatomy;
- adult-vs-child safeguard;
- explicit comparison against Human.

This is the species skeleton.

A Species Anatomy Core must answer:
> What makes this species structurally different before hair, clothes, skin color, profession or props are added?

## Step 4 — Define controlled within-species variation

Only after Anatomy Core is stable:
- define finite chassis where useful;
- define narrow stature variation;
- define age/sex/face/hair variables;
- define lineage variation when official rules require it.

No chassis may violate the Anatomy Core.

## Step 5 — Apply approved board/rendering grammar

Only now inherit:
- accepted VA03-HUMAN board layout;
- VA01 line language;
- VA01 flat color / cel shading;
- current positive VA02 Face Grammar;
- simple neutral calibration clothing.

The Human Board is a **board/rendering template only**.
It is never a species-anatomy source for non-Humans.

## Step 6 — One-sample species preflight

Before a six-person species board, generate/edit one sample.

The preflight must test two things independently:
1. **species anatomy matches official + VA01 species exemplar**;
2. **rendering/board style matches accepted VA01/Human visual grammar**.

Fail if either side is wrong.

## Step 7 — Full six-sample board

Only after the preflight passes:
- generate the planned chassis/identity variation;
- run internal QC;
- compare against official facts;
- compare against VA01 species exemplar;
- compare rendering against VA01 / accepted Human Board;
- then present for human review.

## Authority split

| Authority | Controls |
|---|---|
| Official 5E / SRD | species facts, size, required anatomy/lineage facts |
| VA01 species exemplar | project visual translation / silhouette / stylized proportion |
| Species SPEC + annotations | controlled stable variation space |
| VA02 Face Grammar | face drawing system |
| accepted Human Board | board layout + rendering consistency only |
| SEED-A | general character-rendering feel |
| text prompt | execution details only |

## Hard reject: cross-species derivation

Never create:
- Dwarf = scaled-down Human;
- Elf = Human + pointed ears;
- Tiefling = red Human + horns;
- Halfling/Gnome = child Human.

Each must derive from its own official facts + its own VA01 exemplar.

## Hard reject: style-only success

A sample is not acceptable merely because the style matches.

If the anatomy is wrong, the preflight fails.

Likewise, correct anatomy in a semi-realistic / 3D / painterly style fails.

Both axes must pass:
- **Species Truth**
- **Project Style**
