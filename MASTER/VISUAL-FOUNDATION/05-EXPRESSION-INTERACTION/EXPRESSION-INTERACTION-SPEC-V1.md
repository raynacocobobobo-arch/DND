# VA05 — Expression & Interaction Spec V1

**Status:** DRAFT SPEC

## Controls
VA05 locks performance intensity and interpersonal readability for dense scenes.

It controls:
- facial-expression range;
- gesture amplitude;
- eye-line relationships;
- two-person and small-group interaction grammar.

It does not lock character identity, faction clothing or scene narrative.

## Required expression set
Show at minimum:
- focused;
- amused;
- suspicious;
- frustrated;
- anxious;
- tired;
- proud;
- surprised;
- covert/sneaky;
- argumentative;
- collaborative/helpful;
- confused/curious.

Expressions should be readable without becoming emoji faces.

## Required interaction set
Show at minimum:
- handing an object over;
- arguing/disagreeing;
- pointing/guiding;
- reading/writing together;
- carrying/repairing;
- hiding/stealing;
- observing/reacting;
- group reaction to one event.

## Performance range
- Idle/neutral is allowed only as connective tissue, not the dominant state.
- Gestures should be strong enough to read at reduced scale.
- Avoid stage-theater overacting where every limb is maximally extended.
- Eye-lines should create local event triangles.

## Board structure
Use 3 bands:
1. face-expression strip;
2. two-person interaction strip;
3. 3–5-person micro-event strip.

## Pass criteria
- same face/line grammar as VA02;
- expressions remain distinct at small scale;
- interactions can be understood without captions;
- no panel feels like a fashion pose lineup.

## Reject conditions
- repeated smile template;
- blank faces;
- all characters looking at camera;
- random gestures without interaction target;
- exaggerated anime reaction faces.
