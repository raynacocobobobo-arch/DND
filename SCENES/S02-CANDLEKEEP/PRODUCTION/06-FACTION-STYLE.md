## Design objective
The Court of Air scene should communicate:
> **one old knowledge institution receiving many different visitors**

Therefore, visual cohesion is built primarily through **institutional function, materials, tools, and behavior**, not through invented heraldry or a parade of unrelated fantasy costumes.

Exact Avowed costume details remain subject to official visual-reference verification before character sheets. Anything below that goes beyond verified official costume evidence is `【PROJECT】`.

## Shared environment palette / materials
`【PROJECT】`
- old pale-to-mid stone;
- parchment / aged paper;
- ink charcoal;
- desaturated leather browns;
- restrained muted cloth colors;
- small role-specific accents rather than saturated team uniforms.

The goal is not monochrome. The environment is subdued so faces, papers, tools, hands, and event islands remain readable.

## Group 1 — Gate-facing Avowed
Includes Gatewarden, Adjutants, guides, some manuscript handlers.

| Attribute | Lock |
|---|---|
| Materials | wool/linen-like layered cloth, practical leather belts/straps, durable footwear `【PROJECT】` |
| Palette | parchment/stone/charcoal/muted brown; limited desaturated accent `【PROJECT】` |
| Silhouette | layered scholarly workwear; neither military uniform nor floor-length “wizard robe” default `【PROJECT】` |
| Armor | generally absent unless a specifically verified role requires it |
| Insignia | **no invented crest**; use rank/duty through cut, tool, position, and grooming until official imagery is verified |
| Tools | ledgers, writing kits, document tags/seals, manuscript cases, keys only when role-appropriate |
| Forbidden | pointed wizard hats as default, glowing runes everywhere, fantasy-school uniforms, color-coded magical houses |

### Rank differentiation
Gatewarden reads through:
- placement and authority;
- cleaner/more formal version of the same institutional language;
- assistants orienting toward them;
- one high-readability duty object.

Do not solve rank by giving the Gatewarden ornate battle armor.

## Group 2 — Registry scribes / record workers

| Attribute | Lock |
|---|---|
| Silhouette | sleeves managed for writing; layered but desk-functional `【PROJECT】` |
| Surface detail | restrained ink wear, document straps, pouches; no slapstick ink explosion |
| Tools | quills/ink, ledger, parchment, wax/seal workflow where appropriate |
| Visual identity | hands, papers, seated/standing work posture distinguish them more than costume color |

## Group 3 — Manuscript handlers / institutional logistics

| Attribute | Lock |
|---|---|
| Silhouette | practical shorter layers; free arm movement; stronger carrying posture |
| Tools | folio cases, book/manuscript boxes, straps, carts only if later spatial verification supports them |
| Visual identity | load-bearing action and object handling |
| Forbidden | generic dockworker styling; oversized fantasy crates that turn the Court into a market |

## Group 4 — Endless Chant
The procession remains visually part of the **Avowed**, not a separate cult.

| Attribute | Lock |
|---|---|
| Base costume | same material/palette family as Avowed |
| Cohesion | repeated rhythm of walking posture, held texts, and recitation behavior |
| Leader | Chanter distinguished by position/attention and modest formal variation |
| Forbidden | invented choir vestments, giant banners, glowing prophecy scrolls unless later sourced |

The procession should read first by **behavioral repetition**, not costume spectacle.

## Group 5 — Seekers
Seekers come from elsewhere and should be visibly less uniform.

| Attribute | Lock |
|---|---|
| Materials | travel-worn cloth/leather appropriate to role/origin `【PROJECT】` |
| Palette | broader than Avowed, but harmonized to scene; normally one main accent per figure |
| Silhouette | travel cloaks, practical layers, satchels/cases, occupational clothing |
| Core prop | each important Seeker should have a readable written-work carrier or document form |
| Forbidden | every Seeker dressed like an adventuring PC; every visitor visibly armed; carnival-level color variety |

### Seeker differentiation priority
1. reason for travel / profession;
2. written work being presented;
3. age/body type;
4. origin/cultural hints;
5. species;
6. color accents.

Species is **not** the first differentiation tool.

## Group 6 — Visiting scholars / couriers / special narrative Seekers
These figures follow the Seeker base but each gets one strong occupational signal:
- expedition journal + weathered field kit;
- clerical commentary volume + modest faith symbol;
- annotated multilingual folio + slips/bookmarks;
- artisan technical manual + role-relevant small tool;
- protected courier case + travel dust.

No one gets a pile of five unrelated “fantasy accessories.”

## Weapons / armor policy
- Candlekeep’s visitor interface is not a battle scene.
- Visible weapons on visitors should be sparse, sheathed, and role-consistent.
- Avowed institutional identity should not become “armed guards everywhere.”
- Any security-specific equipment must be sourced or explicitly justified later.

## Magic policy
Magic may appear only as work:
- Detect Magic inspecting a specific item;
- Identify / Comprehend Languages represented only if the exact action is understandable and does not turn into a glow effect;
- Mage Hand or similar utility use only if it solves a visible task.

No ambient floating spell effects merely to prove this is D&D.

## Face / grooming / repetition control
Within each group:
- vary age, face shape, hair, skin tone, body type, wear, and personal detail;
- preserve the shared material/silhouette language;
- avoid clone faces and identical robe cuts;
- no “every scholar has long white hair” stereotype.

## Scene-wide contrast hierarchy
1. **Avowed vs Seekers** — institution vs traveler.
2. **Duty groups inside Avowed** — behavior/tool difference.
3. **Individual roles** — body, age, carried work.
4. **Species** — anatomy, not costume gimmick.
5. **Micro-color variation** — lowest priority.
