导入外部 GLB 模型

模型保存在此浏览器；刷新后可恢复。

普通 JSON 仅保存模型引用；跨浏览器移动请导出「完整工程」，包含模型原文件。GLB 导入后在下方素材库点选放置。

模块组合

Shift 多选后组合；组合可整体平移，并在 JSON 中保留分组。外框贴边不等于顶点焊接，几何无缝合并仍需检查边缘。

扫描游戏模型中…

按建筑、植被、礁石、船只、营地道具与海怪分类；每个缩略图由实际 3D 模型生成，单击后在地图上放置。可切换「细节零件」继续选择独立构件。

地图海域尺寸

宽度、深度可分别填写，可扩大或缩小。新增区域默认全部为原版风格海面，原岛屿与模型保持坐标不变。缩小时若会裁掉已编辑内容，则阻止操作。此设置不影响正式游戏尺寸。

地图模板

打开编辑器默认显示真实 V35 岛屿及灯塔、树木、礁石和木屋。146 × 129 是外围扩展规划画布；现有游戏核心海域约 32.7 × 28.9。点击「清空新增地形」不会删除原版岛屿。

选择工具：单击选择 / Shift 多选 / Delete 删除　·　移动 G / 旋转 R / 缩放 S　·　右键旋转视角

场景对象管理器

加载场景对象中…

单击定位并选中；Shift + 单击多选。眼睛图标可隐藏或恢复对象，锁定后不会被误拖动。原版物件隐藏后也可在这里找回。

3D 变换工具

点击物体后修改参数，按 Enter 确认。Delete 删除选中物体。

移动手柄具有 X / Y / Z 三轴，可沿 Y 轴升降对象；旋转绕 Y 轴，缩放保持等比例。多选时支持三轴整体平移。

选中对象

点击原游戏或新增的完整模型，即可单独选中；原版模型可隐藏、恢复，新增模型可删除。地形与海面不参与单选。

Y=0 为原放置高度；正数向上抬升，负数下沉。原版模型同样适用。

操作提示

地形笔刷可拖动绘制。修改会自动保存在本浏览器，点击「试玩当前地图」即可进入独立 V35 试玩环境，使用当前草稿中的模型和地形；正式游戏始终保持原版不变。可另行导出 JSON 备份。
