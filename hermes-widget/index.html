在 iPhone 上操作

  1. 先安装 Scriptable。
  2. 在此页面点击「复制 V2 脚本」。
  3. 打开 Scriptable，点右上角 ＋ 新建脚本，长按编辑区域并粘贴，命名为 Hermes To Do。
  4. 点击 Scriptable 里的运行按钮，粘贴腾讯云 Agent 私聊给你的只读令牌，完成配对。
  5. 返回 iPhone 桌面，长按空白处 → 添加小组件 → Scriptable → 选择中尺寸 → 编辑小组件并选择这个脚本。

关于安全与数据

这里公开的只有小组件程序，没有你的令牌、密码、任务内容。只读令牌只需要在你自己的 Scriptable 中输入，不要发到聊天或上传至 GitHub。

服务器已上线。如果显示 0 项，可能是因为腾讯云 Hermes 数据库目前没有任务；如果网站确有任务却显示 0，请先核实使用的是腾讯云版本还是 GitHub Pages/Supabase 版本。
