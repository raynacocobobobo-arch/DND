## 当前已实现

- 主页、10 卷完整 V3.7 原文，原本的 11 场远征和禁阅卷宗逐段保留
- 站内全文检索（包括人物、战役、年份和完整正文）；所有条目可打开原文章节/段落
- 桌面目录、右栏本卷索引，手机抽屉导航
- 字号调节、纸张/夜间阅读、进度条和继续阅读

## 如何运行

**快速**：解压本 ZIP，打开 `index.html`。网页搜索索引作为本地 JS 文件打包，不需要联网请求。

**本地静态服务**（如果浏览器限制 `file://` 路径）:

```bash
cd severed-ember-codex
python3 -m http.server 8765
# 浏览 http://127.0.0.1:8765/
```

**腾讯云 Nginx**：将整个文件夹的内容部署到独立站点目录（例如 `/var/www/severed-ember/`），由 Nginx 以静态文件方式发布；无需 Node.js、数据库、Docker。可部署在任意子路径，CSS/JS/HTML 使用相对路径。无任何联网 API。

## 重新从原稿构建

```bash
pip install markdown-it-py beautifulsoup4
python3 build.py
```

注意：`build.py` 会重写主页和 10 卷的 HTML，以及本地检索索引；不会修改 `source/` 中的原稿。
