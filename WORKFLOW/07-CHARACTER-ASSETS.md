# 07 — Scene-Specific Character Assets

## Purpose
Build the actual cast for this one level.

## Inputs
- Gate 2 approvals

## Required work
- Use the approved spec and MASTER documents.
- Preserve evidence labels: `【SRD-5.1】`, `【SRD-5.2.1】`, `【OFFICIAL-SETTING】`, `【OFFICIAL-INDEX】`, `【PROJECT】`.
- Record unresolved facts instead of filling them with generic fantasy assumptions.

## Output
- `PRODUCTION/07-60-CHARACTERS.csv + character sheets`

## Gate relationship
- **Gate 3**
- No downstream stage starts before its required gate is approved.

## Pass criteria
- normally 55–70 figures; default around 60; all required cast readable and role-correct.

## Failure return
- Stage 07.

## Do not
- global actor library; arbitrary species variety; unreadable full-body sheets.
