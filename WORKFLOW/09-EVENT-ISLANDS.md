# 09 — Event Islands

## Purpose
Organize the crowd into readable interaction groups.

## Inputs
- Gate 3 assets

## Required work
- Use the approved spec and MASTER documents.
- Preserve evidence labels: `【SRD-5.1】`, `【SRD-5.2.1】`, `【OFFICIAL-SETTING】`, `【OFFICIAL-INDEX】`, `【PROJECT】`.
- Record unresolved facts instead of filling them with generic fantasy assumptions.

## Output
- `PRODUCTION/09-EVENT-ISLANDS.md`

## Gate relationship
- **Gate 4**
- No downstream stage starts before its required gate is approved.

## Pass criteria
- 8–12 islands; normally 3–7 figures each; actions/eye-lines/props defined.

## Failure return
- Stage 09.

## Do not
- uniform crowd scatter; isolated posing.
